## 통합신청곡이란?

여러 플랫폼의 방송 채팅에서 들어오는 신청곡을 **하나의 대기열**로 모아 관리하고, 방송 화면(OBS)에 표시할 수 있도록 돕는 Windows 데스크톱 프로그램입니다.

시청자는 채팅에 아래와 같이 입력하여 곡을 신청할 수 있습니다.

```text
!신청곡 가수 - 제목
```

> 플랫폼별 수집 가능 범위는 Weflab·Toonation 연동 상태 및 원본 서비스의 채팅 표시 방식에 따라 달라질 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 통합 신청곡 대기열 | 플랫폼·신청자·곡명·후원 금액 표시, 중복 제한 |
| YouTube 검색 및 재생 | 검색 결과를 대기열에 추가하고 곡에 영상 링크 연결 |
| 순서 변경 | 드래그로 대기열 순서 저장 |
| 자동 다음곡 | 곡 종료 시 다음 신청곡으로 이동하도록 설계 |
| OBS 오버레이 | 신청곡 목록을 방송 화면에 표시, 디자인·글꼴 설정 |
| 편의 기능 | 접수 ON/OFF, 라이트/다크, 단축키, 로그, 라이선스 인증 |
| 플랙스TV | Weflab 통합채팅 플랫폼 표시 및 명시된 렉스 수량의 후원액 환산(실방송 검증 필요) |

실제 YouTube 영상의 임베드 및 자동 재생 여부는 YouTube의 재생 조건·정책에 영향을 받습니다.
